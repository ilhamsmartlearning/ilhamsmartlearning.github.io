HTML atau HyperText Markup Language merupakan sebuah bahasa untuk membuat halaman web.

Penanda atau markup ini, nanti akan kita sebut dengan Tag.

✓

1. Gunakan Stater Template Pada Halaman Ini

Pada halaman Trinket kamu akan belajar bagaimana cara kode HTML menyusun sebuah halaman website seperti Google atau Youtube sehingga dapat kita nikmati seperti saat ini.

✓

2. Penjelasan Kode Yang Digunakan

  • <HTML>
    • - Merupakan tag utama yang membungkus seluruh isi website.
  • <head>
    • - Berisi penanda informasi utama sebuah website.
  • <body>
    • - Merupakan isi konten utama dari sebuah website.

Kode-kode tadi adalah stuktur utama dari website yang sering digunakan. Berikutnya kita akan belajar tag yang digunakan untuk memperindah halaman website.

✓

3. Tag <title>

Tag ini digunakan untuk memberikan judul pada bagian atas website

✓

4. Tag Heading

Heading adalah sebuah judul yang biasanya diberikan pada halaman atau beberapa bagian dari artikel.

Judul pada HTML dapat kita buat dengan tag <h1> sampai <h6>. Tag <h1> digunakan pada judul level pertama. Lalu tag lainnya digunakan pada sub heading atau level berikutnya.

Setelah kamu memahami tentang heading. Selanjutkan kita akan memahami tentang pembuatan paragraf. Paragraf dibuat dan dipisashkan dengan menggunakan tag p

✓

5. Tag Paragraf

Paragraf adalah kumpulan dari beberapa kalimat. Pada web, Paragraf biasanya digunakan untuk menampilkan teks atau artikel.

Paragraf pada HTML dibuat dengan tag <p>. Selain tag ini, ada juga tag pendukung lain seperti <div>, <hr>, <br>.

Tuliskan kode seperti ini.
